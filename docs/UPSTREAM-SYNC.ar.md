# 📖 الدليل المرجعي: كيفية سحب التحديثات المستقبلية من مستودع سالم بأمان (Upstream Sync Runbook)

هذا الدليل هو مرجعك التشغيلي الدائم لمعرفة الخطوات الصحيحة والآمنة 100% لسحب أي تحديثات جديدة يرفعها سالم على مستودعه، ودمجها في مشروعك المحلي، ورفعها على مستودعك الخاص دون أي مساس بمستودع سالم.

---

### 💡 المفاهيم الأساسية في جهازك:
* **`upstream`**: مستودع سالم الخارجي (`https://github.com/salem-cell/scm-ops-laravel.git`).  
  *(مضبوط في مشروعك للقراءة فقط `DISABLE (push)`؛ يستحيل على Git إرسال أو رفع أي كود إليه).*
* **`origin`**: مستودعك الخاص على حسابك في GitHub (`https://github.com/EngYemen21/scm-ops-2.git`).  
  *(هو وجهتك الوحيدة للرفع والحفظ).*

---

## 🧭 المخطط السريع للعملية (3 دقائق):
```text
1. فحص الجديد (Fetch) ➔ 2. قراءة التحديثات (Log) ➔ 3. نسخة احتياطية (Branch)
➔ 4. دمج التحديثات (Merge) ➔ 5. تحديث قاعدة البيانات (Migrate) ➔ 6. الرفع لحسابك (Push)
```

---

## 🛠️ الخطوات التفصيلية خطوة بخطوة

### الخطوة 1: فحص هل هناك تحديثات جديدة لدى سالم؟ (دون لمس ملفاتك)
افتح التيرمينال (PowerShell أو Git Bash) داخل مجلد المشروع ونفذ:
```bash
git fetch upstream main
```
* **ماذا يفعل؟**  
  يتصل بمستودع سالم عن بُعد ويتحقق من وجود أي تحديثات جديدة وينزل سجلها في الذاكرة المعزولة، **دون أن يعدل أو يلمس أي ملف في مشروعك**.

---

### الخطوة 2: استعراض التحديثات الجديدة وقراءتها
لمعرفة ما هي التحديثات التي أضافها سالم ولم تكن موجودة لديك:
```bash
git log HEAD..upstream/main --oneline
```
* **إذا لم تظهر أي نتائج:** يعني أن مشروعك متطابق مع سالم ولا توجد أي تحديثات جديدة لديه.
* **إذا ظهرت أسطر:** ستظهر لك عناوين وتفاصيل التحديثات الجديدة التي رفعها سالم.

*(اختياري)* لمعرفة أسماء الملفات التي تغيرت بالتحديد:
```bash
git diff --stat HEAD..upstream/main
```

---

### الخطوة 3: إنشاء فرع احتياطي للأمان التام (Safety Net)
قبل البدء بعملية الدمج، احفظ نقطة رجوع فورية لحالتك الحالية:
```bash
git branch backup-today
```
* **الفائدة:** يضمن لك إمكانية التراجع الفوري إلى وضعك الحالي في ثانية واحدة إذا لم تعجبك التحديثات.

---

### الخطوة 4: حفظ أي تعديلات محلية قيد العمل (Stash)
إذا كانت لديك ملفات قيد التعديل محلياً ولم تقم بعمل Commit لها بعد:
```bash
git stash push -m "my-temp-work"
```
* **الفائدة:** يحفظ تعديلاتك جانباً في الخزنة لتجنب أي تعارض، ويجعل مجلد العمل نظيفاً للدمج.

---

### الخطوة 5: دمج التحديثات الجديدة في مشروعك
الآن قم بدمج كود سالم في فرعك الرئيسي `main`:
```bash
git merge upstream/main
```
* **ماذا يفعل؟**  
  يقوم بتحديث ملفات مشروعك المحلي فوراً بآخر كود وميزات رفعها سالم.

ثم أعد تعديلاتك المحلية التي حفظناها في الخطوة 4 (إن وجدت):
```bash
git stash pop
```

---

### الخطوة 6: تحديث قاعدة البيانات والتبعيات
بعد سحب الكود الجديد، قد تكون هناك جداول جديدة أو حزم مضافة:
1. **تحديث الجداول في قاعدة البيانات:**
   ```bash
   php artisan migrate
   ```
2. **تحديث الحزم البرمجية (إذا أضاف سالم مكتبات جديدة):**
   ```bash
   composer install
   npm run build
   ```

---

### الخطوة 7: رفع التحديثات إلى مستودعك الخاص على GitHub
الآن مشروعك المحلي أصبح محدثاً بالكامل ويعمل. لرفع هذه النسخة المحدثة إلى حسابك الشخصي فقط:
```bash
git push origin main
```
* **تأكيد أمان:** هذا الأمر يرفع التحديثات إلى حسابك الشخصي فقط (`origin`)، ولا يقترب من مستودع سالم أبداً.

---

## 🚨 خطة الطوارئ: كيف تتراجع فوراً إذا لم تعجبك التحديثات؟
إذا قمت بالدمج ثم لاحظت وجود مشاكل أو لم ترغب بالتحديثات، اكتب هذا الأمر:
```bash
git reset --hard backup-today
```
* **ماذا يفعل؟**  
  سيعيدك هذا الأمر في ثانية واحدة إلى النقطة التي كنت عندها قبل الدمج، وكأن شيئاً لم يحدث!
